# Route SMS

Android-приложение для пересылки входящих SMS с разных SIM-карт в Telegram.

Route SMS автоматически определяет установленные SIM-карты и позволяет назначить отдельного Telegram-бота и чат для каждого номера. Настройки сохраняются, поэтому после перестановки или временного извлечения SIM-карты её маршрут не пропадает.

## Возможности

- пересылка входящих SMS в Telegram с указанием отправителя;
- отдельные настройки для каждой обнаруженной SIM-карты;
- сохранение ранее зарегистрированных SIM-карт после их извлечения;
- маршрут **Default** на случай, если SIM не удалось определить или её собственный маршрут не настроен;
- отдельный **Служебный чат** для heartbeat-сообщений и ошибок;

Формат пересылаемого сообщения:

```text
От: +71234567890
Текст сообщения...
```

## Подготовка Telegram

Для работы понадобятся токен Telegram-бота и Chat ID получателя.

### 1. Создание бота и получение токена

1. Откройте в Telegram [@BotFather](https://t.me/botfather?startapp).
2. Нажмите **Старт**, а затем откройте приложение BotFather.
3. Выберите создание нового бота.
4. Укажите отображаемое имя бота.
5. Придумайте уникальное имя пользователя, оканчивающееся на `bot`, например `my_sms_router_bot`.
6. После создания откройте данные бота и скопируйте **Bot Token** — строку вида `123456789:AA...`.

Токен даёт полный доступ к боту. Не публикуйте его и не добавляйте в Git. Если токен стал известен посторонним, перевыпустите его через BotFather.

### 2. Получение своего Chat ID

1. Откройте в Telegram [@userinfobot](https://t.me/userinfobot).
2. Нажмите **Старт**.
3. Бот пришлёт сведения о вашем аккаунте. Скопируйте числовое значение **Id** — это ваш **Chat ID**.

### 3. Запуск созданного бота

Перед тестированием обязательно откройте созданного вами бота и нажмите **Старт**. Telegram не разрешает боту первым начинать личный диалог с пользователем.

### 4. Ввод данных в Route SMS

1. Запустите Route SMS и выдайте запрошенные разрешения телефона.
2. В верхнем выпадающем списке выберите SIM-карту, **Default** или **Служебный чат**.
3. Введите полученный **Bot Token** и **Chat ID**.
4. Для SIM-карты при желании задайте псевдоним — он будет отображаться вместо номера.
5. Нажмите **Тестовое сообщение** и убедитесь, что сообщение пришло в Telegram.

Одного и того же бота и Chat ID можно использовать для нескольких маршрутов. При необходимости для разных SIM-карт можно создать отдельных ботов или указать разные чаты.

## Маршрутизация

При получении SMS приложение сначала ищет настроенный маршрут конкретной SIM-карты. Если у него нет токена или Chat ID, используется маршрут **Default**.

В **Служебный чат** отправляются heartbeat-сообщения и сведения об ошибках пересылки. Этот маршрут не используется для обычных SMS.

Активные SIM-карты выделены в списке цветом, неактивные отображаются приглушённо. Кнопка обновления рядом со списком повторно считывает SIM-карты, находящиеся в слотах телефона.

## Требования

- Android 7.0 или новее (`minSdk 24`);
- Android SDK 35 для сборки;
- JDK 17 или новее;
- подключение к интернету для отправки сообщений в Telegram.

## Сборка

### Android Studio

1. Откройте папку проекта в Android Studio.
2. Дождитесь синхронизации Gradle.
3. Выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

### Командная строка

Windows:

```powershell
.\gradlew.bat testDebugUnitTest assembleDebug
```

Linux или macOS:

```bash
./gradlew testDebugUnitTest assembleDebug
```

Debug APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Debug-сборка устанавливается как отдельное приложение **Route SMS Dev** с идентификатором `club.ithueti.routesms.dev`. Release-сборка использует идентификатор `club.ithueti.routesms` и не содержит суффикса `.dev`.

## Разрешения

Приложению необходимы:

- доступ к состоянию телефона и номерам SIM-карт — для определения SIM и слота;
- получение SMS — для запуска пересылки;
- доступ к интернету — для обращения к Telegram Bot API.

Если все разрешения выданы, кнопка в приложении становится неактивной и показывает статус **«Разрешения есть»**.

## Хранение данных и безопасность

Bot Token, Chat ID и сведения о маршрутах хранятся локально в `SharedPreferences` приложения. Не публикуйте резервные копии данных приложения и не передавайте APK вместе с выгруженными настройками.

Текст SMS отправляется только в Telegram-чат, указанный для выбранного маршрута. Служебный чат получает только heartbeat-сообщения и сведения об ошибках.
